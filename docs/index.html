READY IN A FEW STEPS.

四个小步骤，开启高效工作流。

一次安装，让之后的每次收集都更轻松。

  1. 01

    下载并解压

    下载插件压缩包，解压到本地固定文件夹，并保留该文件夹。

    获取插件 ↗
  2. 02

    打开扩展管理

    在 Chrome 地址栏输入以下地址，然后按回车键。

    chrome://extensions
  3. 03

    开启开发者模式

    找到扩展管理页面右上角的「开发者模式」，将开关打开。

    开发者模式
  4. 04

    加载插件文件夹

    点击「加载已解压的扩展程序」，选择刚才解压的文件夹，即可开始使用。

    ＋ 加载已解压的扩展程序

安装完成后，打开支持的商品详情页，点击「获取图片」即可使用。
